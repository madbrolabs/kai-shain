# KAI Lab サイト

- `docs/` … 公開のサイト（GitHub Pages）。`docs/index.html` が会社紹介、`docs/shain/` が社員ページの入口。
- 社員ページの中身は `docs/shain/data.enc.json` に暗号（AES-GCM）で入っていて、合言葉を持つ人の画面の中でだけ開きます。合言葉と元の中身はこの倉庫に入れません。
- `atsume/atsume.py` … 毎日の開発の記録から社員ページの中身を集める係。
- `atsume/fuu.mjs` … 集めた中身に錠をかける係（合言葉ごとに PBKDF2-SHA256 25万回で鍵を包む）。
- `mon/mon.py` … 門番（このPCの 127.0.0.1:8802・トンネルの先）。社員ページ・亀井ページの「試す」「参加したい」「届いた更新（見るだけ）」を受け持つ。決めの口は外の道では 403／404 で断る。
- `mon/kanri.py`・`mon/kanri.html` … 管理画面（社長の決め事＝採用・見送り・招待・お客の案の入れて／見送り だけの別のクライアント）。門番と同じ中で 127.0.0.1:8807 だけで聞き、トンネルにも公開の置き場にも載せない。Host・合言葉（起こすたびに作り直す）・Origin を確かめる。みんなの画面には決めのボタンを置かない（通達 T1795712323）。
- `mon/kanri_hiraku.py` … デスクトップの近道「KAI 管理画面」から pythonw で呼ぶ（窓を出さない。門番が眠っていれば予定の仕事 KAISHAIN_mon を起こし、管理画面だけをアプリの窓で開く）。
- `mon/kai.py` … 社員ページの ID の入口（2026-11-27 社長「普通にIDとPASSで入る方式に」）。入口は全員共通の1本＝トンネルの `/kai/`（門番の `/kai/shain/` に社員ページを出す）。ID とパスワードで入り、その端末には長く残る札（HttpOnly・道は /kai・180日）を置く。名前は ID で自動（チャット部屋・感想も）。社長の ID だけが社長の箱。ID の発行・止める・戻す・パスワードの作り直しは管理画面だけ（初めのパスワードは作った時に1回だけ出す・置き場は内緒の場所の `secret/kai_id_shoki.json`）。本人は社員ページの「パスワードを変える」で替えられる。パスワードは scrypt で混ぜて内緒の場所の `kai_id.json` に置く。間違いが続くと ID ごと・場所ごとに少し止める。前の一人ずつの長いアドレスは消さずに、新しい入口への案内を出す。テスト中のアプリの一覧（`docs/iriguchi/ichiran.json` の `tesuto: true` の行）と感想（写真付き可・内緒の場所の `kansou/`）もここ。感想は管理画面で読み、そのアプリの主任の部屋（行の `shunin`）へも届ける（届かない時は待って何度か届け直す）。
- `mon/kyouryoku.py`・`mon/kyouryoku.html` … 協力者の広場（協力者だけのチャットと掲示板）。入口は一人ずつ＝社長・亀井さん・岩田くん・勝山さんの専用ページ（`/kamei|kyaku/<鍵>/kyouryoku/`）の「協力者の広場」だけ（違う鍵は404・みんなで共通の鍵は止めた）。名前の欄は無く、入った鍵で名前が自動で付く（社長の鍵＝社長、ほかは専用ページの呼び方。替える時は内緒の場所の `kyouryoku.json` の namae）。社長の鍵の時だけ書き込みを消す・掲示板のピン留め。書き込みは内緒の場所の `kyouryoku/kaki.jsonl`、入/切は同じ `kyouryoku.json` の iri。新しい協力者は専用ページを作れば広場にも入れる。写真・ファイル（📎・スマホはカメラからも・1つ20MBまで・写真は送る前に縮める）は内緒の場所の `kyouryoku/fairu/` に置き、鍵の道の下だけで出す（社長が消すと添付も出なくなる）。スマホへの知らせは Web Push（`mon/webpush.py`・アプリ不要・「🔔 知らせを受け取る」で登録＝内緒の場所の `kyouryoku/tsuuchi.json`・送り主の鍵＝`secret/kyouryoku_vapid.json`・暗号の部品＝内緒の場所の `pylib` の cryptography）。iPhone はホーム画面に追加した時だけ届く。入/切は `kyouryoku.json` の fairu・tsuuchi。社員ページ（docs/shain）の端にも「💬 チャット部屋」の小窓で出す（ドラッグで動く・＿で丸に小さく・場所と大きさは端末ごとに覚える・スマホは丸から）。広場のアドレスは専用ページの「社員ページ」の札が #kyo= で渡す（# の後ろなのでサーバーへは行かない）か、小窓に自分の専用ページのアドレスを貼る。小窓の中は ?mado=1（看板・説明を隠す）。広場のページは madbrolabs.github.io の中にだけ出してよい（frame-ancestors）。
- `hikkoshi/` … 引っ越しの型（準備だけ・まだ移さない。社長の通達 T1795792657「正式になったら2で」）。門番を借りたサーバー（Ubuntu）へ移す時の手順（`手順.md`）・入れる命令（`setup.sh`）・常に動かす設定（`kai_mon.service`）・入口（`Caddyfile`・`shain.<ドメイン>`）・移す物の表（`*_mono.txt`）・PC とサーバーの間でデータを送る係（`noboru.py`）・前のアドレスを新しい住所へ回す係（`annai.py`）・外から確かめる道具（`tashikame.py`）。管理画面はサーバーの 127.0.0.1 だけで聞き、社長の PC から tailscale の中の ssh でだけ開く。
- `docs/shain/kidou_logo.js` … 社員ページを開いた時の起動ロゴ（全社の型 1.2.1 を写した・中は書き換えない・名前「社員ページ」・KAI のロゴがピランと出る）。雰囲気を選ぶ口は部屋の一覧の下の「起動の画面」（ボタンの数と名前は部品から取る・選んだ物は端末が覚える・既定＝近未来）。
