## 2 サーバーを用意する（お金の所は社長）

1. 借りる。Ubuntu 24.04・メモリ 1GB 以上・ディスク 10GB 以上が目安（データは今 約100MB。広場の添付で増える）。
2. ドメインを買った所の画面で、`shain.kailab.co.jp` をサーバーの番地へ向ける（A。あれば AAAA も）。
3. サーバーで、root で：
   ```
   git clone https://github.com/madbrolabs/kai-shain.git /srv/kai_shain
   cd /srv/kai_shain && git checkout --detach <本番と同じコミット>
   bash /srv/kai_shain/hikkoshi/setup.sh kailab.co.jp
   ```
4. `tailscale up --ssh --hostname=kai-server`（社長のアカウントで入る）。これでサーバーは tailnet の中で `kai-server` と呼べる。
5. 社長の PC から ssh が通るか確かめる：
   - 鍵が無ければ `ssh-keygen -t ed25519` で作る。
   - 公開鍵（`.pub` の方）を、借りた所の画面からサーバーの `/root/.ssh/authorized_keys` に足す。
   - `ssh root@kai-server true` が通れば良し。
6. 外から開ける口をしぼる時：
   ```
   KAI_UFW=1 bash /srv/kai_shain/hikkoshi/setup.sh kailab.co.jp
   ```
   - 開くのは 80・443・ssh・tailscale だけ。門番（8802）と管理画面（8807）は、もともと 127.0.0.1 だけで聞く。
   - ssh を tailscale の中だけにする時は、tailscale で入れるのを確かめてから `ufw delete allow OpenSSH`。
