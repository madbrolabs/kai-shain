入口アプリ

会社のソフトを、押すだけで入れます

まず、入口アプリを入れます

    ホーム画面に置くと、次からすぐ開けます

    1. 画面の下にある 「…」 か 共有のしるし（四角から上向きの矢印） を押します
    2. 「共有」 → 「ホーム画面に追加」 を押します（見当たらない時は、下へ送るか 「その他」 を押すと出ます）
    3. 右上の 「追加」 を押せば出来上がりです

    招待のリンクを受け取ります

    会社から届いた招待のリンクを、長押しして「コピー」してから、下のボタンを押してください。

    うまくいかない時（手で貼り付ける）
