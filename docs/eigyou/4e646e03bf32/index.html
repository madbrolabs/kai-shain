リバベル ＋ 超議事録

これまで言葉が通じず、笑ってごまかすだけ。商談にならず、そもそもお店で受けられなかった。
つながると
  1. いつもの営業が、いつもの展示場で、通訳なしで一人で商談できる
  2. 話した中身が、自動で議事録になる
  3. そのまま上司に届く
  4. 会社の記憶として、みんなに共有される

リバベル ＋ 縁ything

これまで共通の言葉がなく、話すことさえ出来なかった。LINEも連絡先も交換できず、一度来た方はそれきり。
つながると
  1. その場で、LINEのように連絡先がつながる
  2. 外国語が話せなくても大丈夫。こちらは日本語で打つだけで、お客様には英語で届く
  3. お客様の返事も、日本語になって届く
  4. 一度きりの来場者が「お客様」になる

縁ything ＋ 超議事録

これまでお客様との連絡は担当者のスマホの中だけ。会社の誰も中身を知らず、担当が替わると話が途切れていた。
つながると
  1. 毎日のやりとりが、お客様ごとの1冊に自動でたまる
  2. 「あのお客様、何て言ってた？」に誰でもすぐ答えが出る
  3. 担当が休んでも替わっても、続きから話せる
  4. 会社みんなの記憶になる
ぜんぶ、くっつくと

3つ全部つながると

  1. 商談できる言葉が通じなかったお客様と、いつもの営業が一人で
  2. 記録が残る話した中身が自動で議事録に。上司にも届く
  3. 連絡が続く外国語が話せなくても、日本語で打つだけで届く
  4. お客様になる一度きりの来場者が、ずっと続くお客様に
  5. 会社の記憶になる誰が担当でも、みんなが続きから話せる

1つずつなら「便利」。3つ全部つながると、これまで出来なかった仕事が、最初から最後まで一本の流れになります。

3つのソフト

超議事録

スマホで録るだけ。会社の話が全部文字で残り、あとから何でも聞ける。

  • 録音はスマホで録るだけで自動で届く
  • 全文の文字起こしと、要点・決まった事・宿題の議事録
  • 「あの件どうなった？」に答える聞ける帳
  • 声で直せる。一度直した名前は二度と間違えない
  • 電話の録音と商談の振り返り近日
単体でも使えます

リバベル（Re:Babel）

世界を一つに。向かい合って話すだけ。お互いの言葉に訳して、見せて、読み上げる。

  • 画面を半分ずつ。対になる文が同時に光る
  • 金額や日付などの数字は強調して見せる
  • 間取り図や写真を差し込んで説明できる
  • 営業が相手の言葉を自分の口で話すモード
  • 翌日に3問だけの練習で、外国語も上達
単体でも使えます

縁ything（エニシ）

外国語が話せなくても、外国のお客様と連絡が取り合える。こちらは日本語のままでOK。社内の連絡にも。

  • 日本語で送れば、相手の言葉で届く。返事は読み上げ
  • 声で送れる。スマホでもパソコンでも
  • 電話番号だけで、スマホを替えても元どおり
  • 点検の時期になったら、ひと言お知らせ近日
  • お客様からの紹介の入口近日
単体でも使えます
